# tadk13
Task 13 — Duplicate Record Check | Superstore Orders

Objective

Identify duplicate records, document the findings, and produce a cleaned analytical copy.

Dataset

Synthetic Superstore-style order data created for the internship task.

Tools

Excel, Python, Pandas

Duplicate Detection

Exact duplicate: complete row is repeated.

Business-key duplicate: Order_Date + Customer_ID + Category + City repeats.

Workbook

The Excel file contains:

README

Raw Data

Duplicate Report

Key Duplicates

Cleaned Copy

Audit Log

Cleaning Rule

Exact duplicate rows are removed while the first occurrence is retained. Business-key duplicates are flagged for investigation instead of automatically deleted.

Key Learning

A professional data analyst should define what makes a record unique before removing data.
